# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately and do not open a public issue for security-sensitive bugs.

Include:

- A clear description of the issue
- Reproduction steps
- Impact assessment
- Suggested remediation (if known)

## Supported Versions

This repository currently supports the latest `main` branch.

## Handling Secrets

Do not commit credentials, tokens, or private endpoints to source control.
Use local `.env` files for configuration and keep them out of git.
